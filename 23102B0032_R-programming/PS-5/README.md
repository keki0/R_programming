# PS-5: Social Network Analysis with R

## Objective

To perform Social Network Analysis (SNA) using R by representing relationships between entities as a network, analyzing its structure, identifying important or highly connected nodes, and visualizing the resulting network.

## Problem Statement

The objective of this problem is to implement a Social Network Analysis workflow using R Programming. Entities are represented as nodes/vertices and relationships between them are represented as edges/links. The network is then analyzed to understand its structure, connectivity, and important nodes.

## Tools and Technologies Used

- R Programming
- RStudio
- R packages for network analysis
- Git and GitHub

## Work Performed

The following tasks were performed as part of this experiment:

1. Prepared the network dataset containing relationships between entities.
2. Represented entities as nodes/vertices.
3. Represented relationships between entities as edges/links.
4. Constructed the social network using R.
5. Visualized the complete network.
6. Calculated network measures to analyze node connectivity.
7. Identified important/highly connected nodes.
8. Generated a degree-based network visualization.
9. Executed and tested the complete R implementation.
10. Interpreted the generated network structure and measures.

## Methodology

The experiment follows the workflow:

**Data Preparation → Network Construction → Network Visualization → Network Measures → Identification of Important Nodes → Interpretation**

### 1. Data Preparation

The network relationship data was stored in `network_edges.csv`. The dataset contains the connections between entities and was used to construct the network.

### 2. Network Construction

The network was constructed using the relationship data.

- **Nodes/Vertices:** Represent the entities in the network.
- **Edges/Links:** Represent relationships or connections between the entities.

### 3. Network Visualization

The constructed network was visualized to understand the relationships and connectivity among the different nodes.

### 4. Network Measures

Network measures were calculated and stored in `network_measures.csv`. These measures were used to examine the connectivity and importance of nodes within the network.

### 5. Degree Visualization

A degree-based visualization was generated to highlight the connectivity of nodes in the network. The resulting visualization is stored as `network_degree_visualization.png`.

### 6. Interpretation

The network visualization and calculated measures were analyzed to identify highly connected and potentially influential nodes and to understand the overall structure of the network.
