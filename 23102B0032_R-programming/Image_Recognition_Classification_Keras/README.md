# Image Recognition and Classification with Keras in R

## Objective

To implement image recognition and classification using a neural network with Keras and TensorFlow in R, and classify images into two categories: Plane and Car.

## Experiment

Image Recognition & Classification with Keras in R.

## Dataset

A small custom image dataset containing:

- 6 plane images
- 6 car images

The images are resized to 28 × 28 pixels and represented using 3 RGB channels.

### Dataset Structure

- p1.jpg to p6.jpg → Plane images
- c1.jpg to c6.jpg → Car images

Five plane images and five car images are used for training. One plane image and one car image are used for testing.

## Technologies Used

- R
- RStudio
- Keras 3
- TensorFlow
- EBImage

## Neural Network Architecture

Input Layer:
- 2352 features (28 × 28 × 3)

Hidden Layer 1:
- 256 neurons
- ReLU activation

Hidden Layer 2:
- 128 neurons
- ReLU activation

Output Layer:
- 2 neurons
- Softmax activation

## Training

Optimizer:
- RMSprop

Loss Function:
- Categorical Crossentropy

Epochs:
- 30

## Classes

- 0 → Plane
- 1 → Car

## How to Run

1. Install **R** and **RStudio**.

2. Install the required packages:
   - `keras3`
   - `EBImage`
   - `TensorFlow`

3. Open `Image_Recognition_Classification_Keras.R` in RStudio.

4. Make sure the `data` folder is located in the same directory as the R script.

5. Run the script section by section.

6. The model will train and classify the test images into **Plane** or **Car**.

## Results

The trained neural network predicts the class of the test images using the probability values generated by the **Softmax output layer**.

The generated outputs and screenshots are available in the following folder:

- `result/`
